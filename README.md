# fullstack-fact-website
simple fullstack website for displaying and voting on facts

# dependencies:
React requires you download nodejs: https://nodejs.org/en
Supabase account required for backend: https://supabase.com/

# Method
React app created by running following command in project root: $ npx create-react-app fact-share

# Project Layout

* app_v1 contains a version of the app using vanila js without React
